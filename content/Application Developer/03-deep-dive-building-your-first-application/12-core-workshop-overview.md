# Lesson 12 — Core Workshop Overview

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944284

## Scope

The core section adds filters, multi-layer visualizations, widget-to-widget variable wiring, tables, and a Gantt chart. These capabilities move the module from a static chart to an interactive decision-support workspace.

## Mental model

Each new widget should answer a specific user question and exchange only the typed state needed by other widgets. Reusing well-named variables keeps filtering behavior consistent across the application.
