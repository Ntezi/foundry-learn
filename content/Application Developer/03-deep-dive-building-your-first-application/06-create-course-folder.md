# Lesson 6 — Create a Course-Specific Training Folder

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1976502

## Official procedure

Favorite the learning project for quick access, choose New > Folder, and name the folder `Deep Dive: Building your first Application`. This folder becomes the installation location for the Marketplace product and the working directory for the Workshop module and later function repository.

## Why it matters

A stable course boundary prevents training resources from being scattered across Compass and makes cleanup, permission review, and reuse straightforward. The name should identify the course rather than a transient step.
