# Lesson 9 — Create a Workshop Application

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944266

## Official procedure

Inside the course folder, choose New > Workshop module. Foundry creates a module with an auto-generated name; rename the resource to `Shipment Operations Center`.

## Resource name versus UI title

This lesson names the Workshop resource itself. A later lesson adds the visible title inside the application header. Keeping these concepts distinct matters because Compass resource discovery and end-user presentation serve different audiences.

## Verification

Confirm the module lives in the course folder and opens in Edit mode under the new resource name.
