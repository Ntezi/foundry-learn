# Lesson 8 — Basic Workshop Overview

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944265

## Goal

Begin the Workshop application with a simple visualization of product-shipment data, then learn the save, publish, and view lifecycle. The lesson's deeper point is that decision support starts by presenting the right ontology-backed evidence to the right user.

## Mastery check

Before adding actions, the application should answer a concrete operational question reliably. A polished interface without the correct object scope does not support a valid decision.
