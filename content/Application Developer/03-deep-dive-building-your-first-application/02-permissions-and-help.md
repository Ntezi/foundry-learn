# Lesson 2 — Permissions & Help

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944243

## Required access

The course uses Compass/Workspace Navigation, Marketplace, and Workshop. Full execution also requires permission to create or edit a learning project, deploy Marketplace resources, and create or edit Workshop applications. If project creation is restricted, an administrator can provide a project and course folder; Workshop editing itself has no course workaround.

## Operational lesson

Generic screenshots are not authoritative for a particular enrollment. Check the local Training application under Support > Training for organization-specific restrictions, naming rules, or deployment guidance. Cosmetic differences are expected as Foundry evolves; permission and security differences are not cosmetic and should be resolved with the platform team.

## Troubleshooting order

1. Confirm the required application is available.
2. Confirm the target project and ontology role.
3. Read local Training guidance.
4. Consult Foundry documentation for product behavior.
5. Escalate enrollment-specific blockers to the platform administrator.
