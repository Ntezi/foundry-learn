# Lesson 5 — Create a Foundry Learning Project

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944246

## Official procedure

From Files > Projects, create a new project in the organization's space with the Default Template. Use a clear name such as `Learning (<username>)` and a description explaining that it contains personal training resources. Portfolio selection is optional. The course suggests changing the broad default collaborator role from Editor to Viewer when training work should not be editable by others.

Do not use Your Files or a home folder as a substitute because some required tools are unavailable there. If project creation is restricted, use an approved project supplied by the platform team.

## Verification

Confirm the project is in the intended space, you have edit rights, and its sharing posture matches training use before adding resources.
