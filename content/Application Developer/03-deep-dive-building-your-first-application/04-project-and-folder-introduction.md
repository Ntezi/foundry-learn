# Lesson 4 — Project and Folder Introduction

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944245

## Resource organization

Every Foundry resource belongs in a Project. The course recommends one personal learning project for all training, with a dedicated folder for each course. Production organization may differ because ownership, lifecycle, sharing, and promotion boundaries matter more than individual convenience.

Use a username-based naming convention wherever the lesson shows `<username>`. This avoids collisions in shared environments and makes resource ownership visible. A course folder also keeps Marketplace assets, Workshop modules, and logic repositories discoverable as one coherent learning unit.

## Design insight

Projects are governance boundaries, not just folders. Before creating resources, decide who owns them, who can edit them, and whether the project is personal training or shared production work.
