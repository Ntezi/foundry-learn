# Lesson 1 — Introduction

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944237

## What this lesson establishes

Workshop is Foundry's point-and-click application builder. A Workshop application, or module, turns the Ontology into an operational interface: users can inspect objects, follow links, make decisions, and write those decisions back through actions. The Ontology is therefore not merely a data source. Object types supply the records, link types supply relationships, and action types define controlled changes.

## Mental model

Think of a module as a typed graph of data and interactions. Widgets render or collect information; variables carry typed values between widgets; actions close the loop by changing ontology objects. This is why the course recommends prior familiarity with the end-to-end workflow and first-ontology courses.

## Mastery check

You should be able to explain why a dashboard that only displays shipment counts is analytical, while a module that lets a manager select a shipment and record a consolidation decision is operational.
