# Lesson 7 — Install the Marketplace Product

Official lesson: https://learn.palantir.com/deep-dive-building-your-first-application/1944248

## Purpose

The Marketplace product supplies the course's Supply Chain Ontology so the remaining lessons can focus on application design. Search the products search bar for `Deep Dive: Building your first Application`, start the installation, enable an installation suffix using your username, select the course folder, and choose an ontology you are allowed to edit.

The installation creates five datasets plus the installation resource and the object types used later. Wait for the build to finish, inspect the installed-resource list, and navigate through the `Installed in` link to the course folder.

## Verification

Confirm the installation completed successfully, the suffix prevents name collisions, the five datasets are present, and Product, Product Shipment, Shipment, Location, and Vehicle object types resolve in the intended ontology. Record the selected namespace and ontology because later action creation must target the same place.
