# Lesson 19 — Course Conclusion

## Course Essentials
The ontology makes data easier to use, creates reusable organizational vocabulary, and provides controlled actions. It models both **nouns**—objects, properties, links—and **verbs**—actions, rules, and side effects.

The three principal tools are:
- Object Explorer for search and lightweight object-set analysis.
- Data Lineage for provenance, dependency, and pipeline state.
- Ontology Manager for semantic and operational definitions.

## Ontology and AI
The ontology gives AI structured, permission-aware operational context and a governed destination for predictions or recommendations. A Flight Alert recommendation belongs near the alert and the human decision it supports, enabling feedback when operators accept or reject it.

Do not confuse semantic grounding with guaranteed truth. AI outputs still need provenance, confidence, validation, authorization, monitoring, and human accountability. An AI recommendation should not silently become an operational fact.

## Mastery model
```text
Sources → pipelines → objects and links → decisions → actions → outcomes → feedback
```

A strong designer can trace both directions: from a displayed property back to evidence, and from a proposed action forward to organizational consequences.

## Final Mastery Check
Design a disruption-management ontology containing Flight, Alert, Airport, Aircraft, Operator, Decision, and Action Log. Define identities, key links, cardinalities, mutable properties, actions, permissions, provenance, and how AI recommendations remain distinguishable from verified facts.
