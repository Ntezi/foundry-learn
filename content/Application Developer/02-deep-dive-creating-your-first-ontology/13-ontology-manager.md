# Lesson 13 — Ontology Manager

## Course Essentials
Ontology Manager is the primary application for creating and maintaining object, link, and action types. Pipeline Builder can define lighter ontology mappings, but Ontology Manager exposes broader semantic and operational configuration.

## Design reasoning
Where a type is authored affects its lifecycle and editability. Choose the owning tool deliberately, based on governance and expected complexity—not convenience during a demo.

## Practical Ontology Engineering
Treat ontology definitions like public APIs. Assign owners, document meaning, review changes, test compatibility, and prefer proposals or branches for controlled promotion. Separate schema design from production publication.
