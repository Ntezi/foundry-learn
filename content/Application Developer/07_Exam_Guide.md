The old note described a PDF-only guide and an outdated six-course track. A current detailed HTML guide is now available and was inspected. Original note preserved in the dated backup. No exam taken or scheduled.

## Current exam facts

Application Developer Associate: 85 sequential questions, three hours, 70% passing score. The framework describes Associate as timed, multiple-choice, open-book and valid for two years. Do not invent topic weights, retake policies, or permission to split the exam across days. Three hours exceeds the two-hour study-day limit; scheduling needs an explicit exception.

The official framework treats Foundry Aware as the recommended foundation; your leadership makes it mandatory. The delivery partner says Associate has no prior certification prerequisite, while Specialist requires passing the corresponding Associate first. Customer/partner eligibility still applies; “no prerequisite” does not mean unrestricted public registration.

## Eight domains in the current guide

| Domain | Preparation focus / evidence needed |
|---|---|
| 1. Ontology Schema Design and Workflow Assembly | Identity, relationships and compatible changes across existing consumers |
| 2. Action Types and Write-Back Patterns | Validation, execution permissions, controlled edits and evidence |
| 3. Ontology Functions | TypeScript/Python v2 or AIP Logic choice, typed queries/results, publishing and diagnosis |
| 4. Workshop Application Development | Variables, events, layout, dependencies, performance and deployment |
| 5. OSDK, APIs, and External Applications | Application registration, OAuth, scopes, pagination, API use and authentication failures |
| 6. Automate and Operational Workflows | Trigger/effect design, ownership, repeated events, recovery and monitoring |
| 7. AIP Logic and AI-Powered Applications | Typed prompts/tools, grounding, evaluation, traces and side-effect control |
| 8. Application Security, Governance, and Operations | Resource/data access distinctions, identities, least privilege and operational diagnosis |

The function speedrun is useful for domains 2–4 and parts of 8. It is not an adequate substitute for the full domain set. Map observed weaknesses to the guide before scheduling an exam.

## Specialist direction

Application Developer Specialist is the provisional next role credential. The Palantir framework describes delivering a working Ontology-backed application through a live hands-on assessment. The [recognized partner’s exam page](https://www.ontologize.com/exams) links its [Specialist guide](https://www.ontologize.com/exam-guides/palantir-application-developer-specialist-exam-guide.pdf). The detailed PDF has not been inspected in this session; review it before setting readiness criteria beyond the broad pathway or registering.
