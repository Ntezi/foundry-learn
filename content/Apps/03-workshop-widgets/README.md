## Widget finder

Start from what the user needs to do. Each row names the widget and the note that covers it.

| The user needs to… | Widget | Note |
|---|---|---|
| Compare many objects by attribute, sort, bulk-select | Object Table | [01](01-core-display-widgets.md#object-table) |
| Skim a few attributes, see pictures | Object List | [01](01-core-display-widgets.md#object-list) |
| See everything about one object | Object View | [01](01-core-display-widgets.md#object-view-property-list-links-object-set-title) |
| Edit a few properties of one object in place | Property List (inline action) | [01](01-core-display-widgets.md#object-view-property-list-links-object-set-title) |
| Edit many rows at once | Object Table inline editing, or Inline Action table | [01](01-core-display-widgets.md#writing-from-the-table) · [05](05-buttons-forms-and-navigation.md#inline-action) |
| Follow links between objects | Links | [01](01-core-display-widgets.md#object-view-property-list-links-object-set-title) |
| Compare categories or see a trend | Chart XY | [02](02-charts-and-maps.md#chart-xy) |
| See totals across two groupings | Pivot Table | [02](02-charts-and-maps.md#pivot-table) |
| See a key number | Metric Card | [02](02-charts-and-maps.md#metric-card) |
| See schedules or overlaps | Gantt Chart | [02](02-charts-and-maps.md#gantt-chart-and-timeline) |
| See where things are (desktop / phone) | Map / Map [Legacy] | [02](02-charts-and-maps.md#map-and-when-to-use-the-legacy-one) |
| Draw a chart no built-in widget can | Vega Chart | [02](02-charts-and-maps.md#vega-chart) |
| Explore data freely | Free-form Analysis, Time Series Analysis | [02](02-charts-and-maps.md#analysis-widgets) |
| Read or annotate a PDF | PDF Viewer | [03](03-media-documents-and-history.md#the-specialised-viewers) |
| See when data was last updated | Data Freshness | [03](03-media-documents-and-history.md#where-data-came-from-and-what-happened-to-it) |
| See who changed what | Edit History, Action Log Timeline | [03](03-media-documents-and-history.md#where-data-came-from-and-what-happened-to-it) |
| Filter a set by properties or links | Filter List | [04](04-filtering-widgets.md#filter-list) |
| Pick one object, a string, a date, a user | Object Dropdown, String Selector, Date and Time Picker, User Select | [04](04-filtering-widgets.md#input-widgets-the-details-that-bite) |
| Run an action, open a link, export | Button Group | [05](05-buttons-forms-and-navigation.md#button-group) |
| Fill in an action form on the page | Inline Action | [05](05-buttons-forms-and-navigation.md#inline-action) |
| Discuss an object | Comments | [05](05-buttons-forms-and-navigation.md#comments) |
| Upload or record files | Media Uploader, Audio Recorder | [05](05-buttons-forms-and-navigation.md#media-uploader-and-audio-recorder) |
| Ask an AI about what's on screen | AIP Chatbot, AIP Analyst | [06](06-ai-observability-and-embedding.md#ai-widgets) |
| Watch a function's health | Observability Chart | [06](06-ai-observability-and-embedding.md#observability-chart) |
| Show another app or web page | Iframe, embedded Foundry apps | [06](06-ai-observability-and-embedding.md#embedding-other-apps) |
