# 06 — Create a Course-Specific Training Folder

## Give this workflow a recognizable home

Inside the Learning Project, the course asks you to favorite the Project, choose **New → Folder**, and name the folder for this course. Its example name is `Speedrun: Your First E2E AIP Workflow`. Favoriting is a navigation aid: it makes the Project easier to find in Foundry's sidebar and home page.

The folder will hold the Articles media set, Document Processing Transform pipeline and outputs, followed later by application-related resources. Keeping the resources together helps you return after a study break without guessing which pipeline was yours.

## Names are navigation; references are dependencies

Renaming a folder can improve clarity, but it does not explain the dataflow. A pipeline references specific inputs and outputs. When inspecting it later, check those actual references as well as the surrounding folder name.

For example, a pipeline inside the correct AIP folder could still reference another learner's Articles media set if the wrong resource was selected. Folder organization reduces confusion but does not replace checking the input identity.

This is familiar from software projects: a correctly named repository can still point at the wrong database connection. Good organization and correct dependency configuration reinforce each other; neither substitutes for the other.

## Keep one local course collection

The local counterpart is this folder under `Learn/Speedrun`. It contains one note per inspected lesson plus the review, source and practice files. The optional Marketplace lesson is labeled `08a` so the required lessons retain their 01–49 numbering.

There is no need for another Application Developer folder or an assistant-specific subfolder. The course belongs in Speedrun even though its concepts contribute to application-development learning. The broader study tracker links to the same maintained files.

## Use the folder as a recovery aid

Before later practical work, check whether the intended course folder already exists and inspect its contents. If you are resuming, understand existing resources before creating similarly named ones. Record the chosen location once in the practice evidence so the pipeline, outputs and later Ontology configuration can be traced consistently.

The course allows renaming through the context menu. That is useful for clarity, but avoid using renaming to hide uncertainty about which resource is active. Inspect resource identity and references first.

**What to remember:** this lesson is about making a multi-resource workflow easy to locate and reason about. Explain how you would distinguish the correct Articles media set from another one with the same name before attaching it to the pipeline.
