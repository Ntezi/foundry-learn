# 05 — Create a Foundry Learning Project

*Module: Project Setup · Inspected September 12, 2026 · Notes: Ready for Review · Practice: Not Started*

## First decide whether creation is needed

If you already have a suitable learning Project from another speedrun, the course allows you to skip creation and continue to the course folder. Reuse the intended Project rather than creating another copy solely because the lesson starts with New project.

When creation is needed and permitted, open Files, choose New project and name it something like `Learning (<username>)`. Add a description explaining its training purpose. Select the organization's namespace if the selector appears, set the default role to Discover as instructed, then choose Create project.

If you cannot create a Project, use an appropriate administrator-provided or otherwise authorized Project. The source warns against using Your files or your home folder because some required tools are unavailable there.

## Why these fields deserve attention

The name and description communicate ownership and purpose. The namespace chooses an organizational context where that option exists. The default role concerns access; it should not be treated as a decorative setting.

The course's default does not prove that all training resources are private or that all required authoring permissions exist. Check effective access in the actual enrollment. Likewise, a Project that lets you open data may not let you create the Ontology assets required by mining.

A familiar comparison is creating a repository in the correct organization. You need not only a name but also a suitable owner, destination and permissions to create related resources. A writable location chosen at random can create confusion for other teams.

## The later verification result

Record whether you reused or created the Project, its identity and the course folder you will use. Confirm that it is the intended training location and that the relevant resource-creation operations are available. This is practical evidence to collect later, not a completed action in this notes pass.

If the required tool is absent, diagnose location and application/authoring access before assuming the input dataset is invalid. At this stage you have not yet reached the data-to-process mapping.

## What to remember from a repeated setup lesson

You have seen similar Project setup in previous courses. The point is not to memorize another sequence of clicks. It is to recognize the common resource context that makes the rest of the workflow manageable. Reusing that context keeps training coherent while the separate course folder prevents assets from being mixed accidentally.

**Review question:** why is “I saved it somewhere I can write” not a sufficient setup check? The resource may be outside a suitable Project, under unclear ownership or in a location that does not support the required tools and dependencies.
