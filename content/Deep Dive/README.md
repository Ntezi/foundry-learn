# Foundry Deep Dives

Detailed notes for Palantir Learn Deep Dive courses. Each course folder follows the same layout as the [Speedrun courses](../Speedrun/README.md): a README, numbered lesson notes, a review guide, practice preparation, sources and corrections, and a lesson manifest.

| Course | What you will learn | Part of |
|---|---|---|
| [Creating Your First Data Connection](Creating%20Your%20First%20Data%20Connection/README.md) | Connect S3, PostgreSQL and a REST API to Foundry, using sources, egress policies, syncs and an external transform. | Foundry & AIP Aware curriculum |
| [Building Your First Pipeline](Building%20Your%20First%20Pipeline/README.md) | Clean, join, validate and aggregate raw data in Pipeline Builder; catch a bad join; segmenting, UDFs, schedules, branches, expectations. | Data Engineer track |

The earlier Ontology and Application deep dives are under [Application Developer](../Application%20Developer/00_Overview.md).
