## Everything lives in a Project

All Foundry resources, including sources, datasets and repositories, live inside a **Project**. For production, the docs recommend one Project per workflow stage (see [recommended Project structure](https://www.palantir.com/docs/foundry/building-pipelines/recommended-project-structure/)).

For training, use one learning Project for all courses, with one folder per course. Mark your resources with your username so they don't collide with other learners'.

**Remember:** a Project is the permission and organization boundary, and a folder organizes within it.

**Review question:** why not keep training resources in your home folder? Some tools can't be used from there (see the next lesson), and Projects carry the right permission model.
