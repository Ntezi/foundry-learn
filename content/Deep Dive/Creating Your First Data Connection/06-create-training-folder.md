# 06 — Create a Course-Specific Training Folder

*Module: Setting up your Project and Folder · Inspected September 23, 2026 · Notes: Ready for Review · Practice: Not Started*

## Steps

1. Star (favorite) the Project so you can find it quickly.
2. **New → Folder**, named after this course.

Keeping one folder per course stops sources, datasets and repositories from different trainings getting mixed up.
