# 05 — Create a Foundry Learning Project

*Module: Setting up your Project and Folder · Inspected September 23, 2026 · Notes: Ready for Review · Practice: Not Started*

## Steps (paraphrased)

1. Files (left sidebar) → **New Project**.
2. Choose your organization's Space if asked, pick the Default Template, and name it, for example `Learning (<username>)`.
3. Add a description that tells others what the Project is for. Role setup can be skipped for training.

If you can't create Projects, use one you're allowed to use. **Don't use "Your files" or your home folder**, because some tools don't work there.

Docs: [Create a Project](https://www.palantir.com/docs/foundry/compass/create-a-project/).

**Review question:** what two things make a Project easy for others to understand? A clear name and a description of its purpose.
