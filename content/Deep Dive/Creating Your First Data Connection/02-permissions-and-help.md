# 02 — Permissions & Help

*Module: Permissions & Help · Inspected September 23, 2026 · Notes: Ready for Review · Practice: Not Started*

## Where to get help

- The **Training app** (Support → Training in Foundry's left navigation) may hold your organization's local rules about creating Projects, uploading data, editing objects or deploying Marketplace products.
- The [Foundry documentation](https://www.palantir.com/docs/foundry).
- training-feedback@palantir.com for course problems. Screenshots may differ slightly from your Foundry.

## Apps you need

Workspace Navigator (**Compass**), **Data Connection** and **Code Repositories**.

## Permissions and admin workarounds

| Permission | If you don't have it |
|---|---|
| Create a learning Project | An admin creates it for you |
| Edit a learning Project | An admin creates the course folder and gives you Editor |
| Upload files | An admin uploads and tells you where to copy them |
| Data Connection app | No workaround; required |
| Control Panel egress policies (S3 module) | An admin enables the policy once for the whole instance |
| External connections in Code Repositories (REST module) | An admin enables the external transforms setting on each repository |

Since the course is modular, you can skip a module you can't or don't need to do.

**Remember:** egress policies and external connections are admin-level. Expect to need platform support in a real enrollment.

**Review question:** which permission has no workaround? Access to the Data Connection app itself.
