# 23 — Set-up a Direct connection Egress Policy

*Module: Data Connection: Relational Database · Inspected September 23, 2026 · Notes: Ready for Review · Practice: Not Started*

## Same pattern as S3

Import the existing policy if there is one, or create a **Direct connection** policy (the training database is public) for the database host on port **5432**, then Save. It's applied to the source automatically.

The lesson notes that this module can involve **two** egress policies. The Enabling an Egress Policy lesson lists both the database hostname and an IP address on 5432.
