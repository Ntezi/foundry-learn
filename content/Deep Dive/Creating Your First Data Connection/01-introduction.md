# 01 — Introduction

*Module: Overview · Inspected September 23, 2026 · Notes: Ready for Review · Practice: Not Started*

## What you will do

In about 60 minutes you connect Foundry to three real, Palantir-provided sources. You don't need your own systems. The modules are independent, so do only the ones you need:

| Module | Source type | Time |
|---|---|---|
| S3 | Cloud object store (AWS S3) | 15 min |
| Relational database | PostgreSQL over JDBC | 15 min |
| REST API | HTTP API read through Python code | 20 min |

## Why Data Connection matters

Connecting sources is often the first step to getting value from Foundry. Data Connection supports cloud object stores, file systems, databases and data warehouses. It handles structured, semi-structured and unstructured data, and **batch, micro-batch and streaming** transfer. It puts complex pipeline setup behind a front-end interface, and Foundry's open architecture works with third-party and open-source tools.
