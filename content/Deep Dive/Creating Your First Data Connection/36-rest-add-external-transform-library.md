# 36 — Add External Transform Library

*Module: Data Connection: REST API · Inspected September 23, 2026 · Notes: Ready for Review · Practice: Not Started*

## Install `transforms-external-systems`

Libraries panel → search **transforms-external-systems** → **Add and install library**. Wait for *BUILD SUCCESSFUL* and *Library installed*.

This library provides the decorator and `Source` objects the transform uses to call external systems. See [using Python libraries](https://www.palantir.com/docs/foundry/transforms-python/use-python-libraries/).
