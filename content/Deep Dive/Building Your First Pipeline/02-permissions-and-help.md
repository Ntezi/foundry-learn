## What you need
**[Course]** Apps: **Workspace Navigator (Compass)** and **Pipeline Builder**.

| Permission | Workaround if missing |
|---|---|
| Create a learning Project | An admin creates it |
| Edit the learning Project | An admin creates the course folder and gives you Editor |
| Upload files | An admin uploads them (or use the [optional Marketplace install](08-optional-deploy-datasets-via-marketplace.md)) |
| Create Pipeline Builder resources | **No workaround.** Required |

**[Course]** Help comes from your enrollment's **Training app** (Support → Training), which covers local restrictions on Projects, uploads, objects and Marketplace. Also the [Foundry docs](https://www.palantir.com/docs/foundry) and training-feedback@palantir.com. Screenshots may differ slightly from the current UI.

## Why this matters
**[Explanation]** Unlike the Data Connection course, this one needs no security-admin permissions such as egress policies. The only hard requirement is the ability to create Pipeline Builder resources in a Project. That makes it one of the easier deep dives to practise in a restricted enrollment.
