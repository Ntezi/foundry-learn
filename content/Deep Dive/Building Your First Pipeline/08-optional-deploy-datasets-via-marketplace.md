## When to use this
**[Course]** Only if you **can't download** the files or **can't upload** to Foundry. Open **Marketplace** → search products (the top *Search products…* box, not *Search stores…*) for **Deep Dive: Building Your First Pipeline** → install the datasets into your course folder. The Building Your First Application course has detailed steps for a similar install.

## What changes downstream
**[Course]** In [lesson 09](09-create-a-new-pipeline.md), choose **Add Foundry data** instead of uploading.

**[Explanation]** A Marketplace install creates the datasets for you, so the JSON may already be handled differently from a manual upload. Check each node's schema before assuming the later steps (such as *Extract rows from a JSON file*) apply unchanged. This is an inference, not stated by the course.
