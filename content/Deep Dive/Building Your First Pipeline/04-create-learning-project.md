## Walkthrough (paraphrased)
**[Course]**
1. Files → **New Project**. Skip this if you already have a learning Project.
2. Name it (for example `Learning (<username>)`) and add a description.
3. Choose your organization's **Namespace** if asked.
4. Set the **Default role to Discover**.
5. Create.

If you can't create Projects, use one you're allowed to use, but **not "Your files" or your home folder**, because some tools can't be used from there.

## Why "Default role: Discover"?
**[Explanation]** Discover lets other people in the organization *see that the Project and its resources exist* without being able to read the data. It's a sensible default for a training Project: discoverable, not readable. Compare the Discoverer role in the Data Connection notes' [permissions discussion](../Creating%20Your%20First%20Data%20Connection/07-basic-concepts.md). This lesson differs slightly from the Data Connection course, which let you skip role setup.
