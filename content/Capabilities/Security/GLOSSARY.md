# Glossary

One line per term, with the official page it comes from and the note that explains it. **All definitions are [Docs] paraphrases.**

Seeded on October 23, 2026 from the docs' [Security glossary](https://www.palantir.com/docs/foundry/security/security-glossary/); terms are added as each module's notes are written (136 terms, modules 00–10 written, October 23, 2026). Ontology permission terms (object security policy, project-based permissions) are in the [Ontology glossary](../Ontology/GLOSSARY.md); application and token terms in the [DevTools glossary](../DevTools/GLOSSARY.md).
