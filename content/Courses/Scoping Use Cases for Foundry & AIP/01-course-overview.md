# 01 — Course Overview

*Module: Overview · Inspected September 23, 2026 · Notes: Ready for Review*

## What this course is for

A short conceptual course (about 10–15 minutes) on two skills:

1. **Prioritizing** candidate use cases for Foundry.
2. **Scoping** a chosen use case with stakeholders, using key questions.

The course calls itself only a starting point for a **"scoping mindset"**. Expect to adapt it to your organization's own guidelines.

**Remember:** prioritize first (which use case?), then scope (what exactly, for whom?).
