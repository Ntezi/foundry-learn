# Review guide — Scoping Use Cases for Foundry & AIP

Explain each answer in your own words before you check the lesson it points to.

## The story in five sentences

1. Prioritize candidate use cases on **business** factors (problem statement, alignment, ROI, urgency), **team** factors (business availability, technical resources, steering and governance) and **data/tech** factors (a best guess, not full technical scoping) ([03](03-business-elements.md)–[05](05-data-and-tech-elements.md)).
2. The most "Foundry-shaped" problems are often **loosely defined** but cause **sharp user pain**. Their impact **crosses organizational areas** through reusable data, and they are **urgent** ([03](03-business-elements.md)).
3. Before kickoff, secure a steering cadence, beta users, a data focal point, data approvals and desk-side walkthroughs. Also set **project gates**: the MVP and a production checklist ([07](07-successful-kickoff.md)).
4. Avoid the pitfalls: tech scoping before business scoping, rebuilding the old workflow as-is, technology without users, skipping desk-sides, aiming for perfection, and scoping for months ([08](08-common-pitfalls.md)).
5. Scope the workflow block by block: data sources, user needs, interactions, data asset, automations, models, permissions and data controls ([09](09-scoping-the-workflow.md)).

## Traps to watch for in exam options

- **"Only scope a use case once the solution is precisely specified."** The course prefers loosely defined problems with clear pain.
- **"Start with a detailed technical architecture."** Business scoping comes first, and technical scoping as late as possible.
- **"Replicate the current process in Foundry."** That is named as a common mistake.
- **"Postpone until data quality is fixed."** Work around it and fix data quality within the platform as part of the use case.
- **"Spend months producing a complete design and user stories first."** Build fast and iterate with users.
- **"Put every dataset in the Ontology."** Keep the Ontology to understandable, workflow-relevant objects.
