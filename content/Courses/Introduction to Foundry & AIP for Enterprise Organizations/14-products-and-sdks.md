# 14 — 3.3 Products & SDKs

*Module: Section 3: North of the Ontology · Inspected September 23, 2026 · Notes: Ready for Review*

## Packaging capabilities for users and systems

Platform capabilities can be packaged into products for internal operators, external customers or other systems.

## Ontology SDK (OSDK)

The OSDK is a **generated** SDK that gives developers programmatic access to the Ontology's data, logic and actions from their own environment: custom React apps, Python backends, Java services, or any language via **OpenAPI**. The course describes it as turning your Ontology into "an SDK of your business". Agentic workflows built with the OSDK can be added to **existing applications**, so current tools are enhanced, not replaced.

## Other integration paths

- Streaming and batch connectors with **export plugins**
- **Webhooks** for real-time writeback to external systems
- **External transforms** that run transformations outside Foundry and bring results back in

**Remember:** OSDK = generated, typed access to the Ontology for your own apps; webhooks and exports = pushing decisions out.

**Review question:** a team wants their existing customer portal to use Ontology data and actions. What does the course point to? The OSDK (or OpenAPI), which enhances the existing app instead of replacing it.
