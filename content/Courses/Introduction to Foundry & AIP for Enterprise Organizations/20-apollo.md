# 20 — Apollo - Software Delivery Layer

*Module: Section 5: Security, Governance & Deployment · Inspected September 23, 2026 · Notes: Ready for Review*

## What Apollo is

**Apollo** is Palantir's platform for autonomous software deployment and management: the engine that lets everything in the course run wherever it needs to.

## Deployment flexibility

Its defining capability is running anywhere: public cloud (AWS, Azure, GCP), on-premises data centers, edge locations, hybrid setups and fully **air-gapped** environments without internet. Enterprises often run several of these at once, and AI infrastructure has to meet them there.

## What it handles

Continuous delivery, configuration management and operational monitoring across all environments, so the same capabilities are available wherever the software runs.

**Remember:** Apollo = delivery and management of the platform across cloud, on-prem, edge, hybrid and air-gapped.

**Review question:** a defense customer needs Foundry in a network with no internet access. Which layer makes that deployment and its updates possible? Apollo.
