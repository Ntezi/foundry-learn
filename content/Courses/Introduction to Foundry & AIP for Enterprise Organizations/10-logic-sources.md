# 10 — 2.2 Logic Sources

*Module: Section 2: South of the Ontology · Inspected September 23, 2026 · Notes: Ready for Review*

## Data tells you what IS; logic tells you how to THINK

Logic sources range from the simple (rules in a spreadsheet, SOPs, tribal knowledge) to the sophisticated (ML forecasting models, third-party route optimizers, custom algorithms).

## Bringing logic in

Models can be built inside the platform or brought in from outside. **Containerized runtimes** let teams package existing model code in Docker containers and deploy it into Foundry.

## MMDP for compute

The Multimodal Data Plane also applies to compute: a **compute-agnostic build framework** lets you mix and match third-party compute runtimes. "Any compute" joins "any storage".

**Remember:** logic can be as informal as an SOP or as formal as a containerized model; all of it can be modeled for humans and AI to use.

**Review question:** a data science team already has a model in a Docker image. How can it reach Foundry? Deploy it through a containerized runtime instead of rewriting it.
