# Glossary

One line per term, with the official page it comes from and the note that explains it. **All definitions are [Docs] paraphrases.**

Terms are added as each module's notes are written (63 terms after modules 00–09, October 8, 2026). Ontology and agent terms already defined in the [Ontology glossary](../Ontology/GLOSSARY.md) (for example OAG, retrieval context, staged writes) are not repeated here.

| Term | Definition | Official page | Note |
|---|---|---|---|
| **Agent Manager** | Where published Agent Stack agents and their sessions are inspected: context items, event history, state, traces and logs | [page](https://www.palantir.com/docs/foundry/aip/agent-stack/) | [00-01](00-orientation/01-what-aip-is.md) |
| **Agent Stack** | Palantir's agent infrastructure and product suite for building, running and observing agents with sessions, context items and events | [page](https://www.palantir.com/docs/foundry/aip/agent-stack/) | [00-01](00-orientation/01-what-aip-is.md) |
| **AI FDE** | Agent that builds in Foundry for you (pipelines, Ontology, functions, apps), as you, on branches, with tool approval | [page](https://www.palantir.com/docs/foundry/ai-fde/overview/) | [07-05](07-end-user-apps/05-ai-fde.md) |
| **AIP Analyst** | Agent for ad-hoc Ontology analysis in natural language; analyses can be saved, embedded and turned into skills | [page](https://www.palantir.com/docs/foundry/aip-analyst/overview/) | [07-04](07-end-user-apps/04-aip-analyst.md) |
| **AIP Assist** | In-platform LLM assistant trained on Palantir documentation; aware of the open app; no access to your data, except the metadata of datasets and objects referenced by code you attach | [page](https://www.palantir.com/docs/foundry/assist/overview/) | [07-02](07-end-user-apps/02-aip-assist.md) |
| **AIP capabilities for custom workflows** | The permission level that unlocks building with LLMs: Logic, Chatbot Studio, Use LLM nodes, LLMs in code and more | [page](https://www.palantir.com/docs/foundry/aip/enable-aip-features/) | [08-02](08-security-governance-and-admin/02-enabling-aip.md) |

| **AIP Threads** | Chat with native PDFs or a published chatbot; full text or relevant chunks | [page](https://www.palantir.com/docs/foundry/threads/overview/) | [07-07](07-end-user-apps/07-threads-evolve-and-realtime-audio.md) |

| **Block (AIP Logic)** | A step in a Logic function: Use LLM, Apply action, Execute function, Conditionals, Loops, Create variable | [page](https://www.palantir.com/docs/foundry/logic/blocks/) | [03-02](03-aip-logic/02-building-a-logic-function.md) |
